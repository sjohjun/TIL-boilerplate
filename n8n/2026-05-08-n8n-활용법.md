### Context
n8n은 다양한 자동화 워크플로우를 설계하고 배포할 수 있는 강력한 툴입니다. 이를 통해 기업은 반복적인 작업을 자동화하고 효율성을 극대화할 수 있습니다. 이번 문서에서는 n8n을 활용한 기본적인 워크플로우 사례를 설명합니다.

### Core
다음은 n8n을 활용하여 간단한 데이터 추출 및 분석 워크플로우를 구현하는 예시입니다.

```json
{
  "nodes": [
    {
      "id": 1,
      "type": "Start",
      "parameters": {},
      "name": "Start"
    },
    {
      "id": 2,
      "type": "HttpRequest",
      "parameters": {
        "url": "https://api.example.com/data",
        "method": "GET"
      },
      "name": "Fetch Data"
    },
    {
      "id": 3,
      "type": "Function",
      "parameters": {
        "functionCode": "return items.map(item => {return {json: {result: item.json.value * 2}}});"
      },
      "name": "Process Data"
    }
  ],
  "connections": {
    "Start": {"main": [[{"node": "Fetch Data","type": "main","index": 0}]]},
    "Fetch Data": {"main": [[{"node": "Process Data","type": "main","index": 0}]]}
  }
}
```

### Insight
위의 예시에서는 HTTP 요청 노드를 사용하여 외부 API에서 데이터를 가져오고, Function 노드를 통해 데이터를 처리합니다. 이를 통해 데이터 추출 및 간단한 변환이 이루어집니다. n8n의 직관적인 인터페이스와 다양한 노드를 통해 워크플로우를 손쉽게 구성할 수 있습니다.
