### Context
n8n을 사용하여 디스코드(Discord) 메시지를 기반으로 자동화를 구축했습니다. 목표는 디스코드에서 특정 메시지를 수신하면 이를 트리거로 활용하여 일련의 자동화 작업을 수행하는 것입니다. 이 작업에는 메시지가 TIL 형식으로 변환된 후 GitHub에 자동으로 커밋하고, README.md 파일을 업데이트하고, 완료 알림을 발신하는 전체 자동화 프로세스가 포함됩니다.

### Core
디스코드 메시지를 트리거로 하는 n8n 워크플로우입니다:

```json
{
  "nodes": [
    {
      "type": "discordTriggerNode",
      "parameters": {
        "event": "messageReceived"
      }
    },
    {
      "type": "agentNode",
      "parameters": {
        "action": "convertToTIL"
      }
    },
    {
      "type": "githubNode",
      "parameters": {
        "action": "pushToRepo"
      }
    },
    {
      "type": "githubUpdateReadmeNode",
      "parameters": {
        "action": "updateReadme"
      }
    },
    {
      "type": "discordSendMessageNode",
      "parameters": {
        "message": "작업이 완료되었습니다."
      }
    }
  ]
}
```

### Insight
n8n을 처음 사용해보았는데, 성공적으로 자동화를 구현하게 되어 뿌듯합니다. 이 플랫폼은 두 가지 핵심 개념, 즉 각 노드의 입력과 출력만 이해하면 쉽게 워크플로우를 구성할 수 있도록 설계되어 있습니다. 이러한 지식을 제공해 준 후츠릿에게 감사의 말씀을 전합니다.
